Bob Logbook

A git shadow-branch AI workspace that automatically captures IBM Bob session context — so your teammates can pick up exactly where you left off.
Python 3 · stdlib only Git plumbing Zero dependencies IBM Bob hooks jaminleod & alexvu31

The Problem

Every time a developer works with IBM Bob, valuable context accumulates: decisions made, prompts that worked, constraints discovered, dead-ends avoided. That context lives only in the chat window. When the session ends, it disappears.

Teammates cannot pick up where someone left off without reading the entire chat history. The developer has to manually extract and document their own session. No one does this consistently.

"As a developer using IBM Bob, I want my AI session context captured automatically in git so my teammate can pick up exactly where I left off — without reading the entire chat history."

Our Solution

Bob Logbook wires two IBM Bob lifecycle hooks (UserPromptSubmit and Stop) into a lightweight Python CLI that writes every turn to a dedicated git shadow branch (bob-context). The shadow branch shares no history with main, so there are never merge conflicts. A companion HTML viewer renders the workspace as a colour-coded browsable timeline — open in any browser, no server required.

BOB LOGBOOK Code Highlights

Hook Configuration

Two Bob lifecycle events fire the same hook wrapper. UserPromptSubmit captures the developer's prompt before it is sent; Stop captures Bob's response after each turn.

.bob/settings.json
{
  "hooks": [
    {
      "event": "Stop",
      "type": "command",
      "command": "python3 .../bob-log-hook.py"
    },
    {
      "event": "UserPromptSubmit",
      "type": "command",
      "command": "python3 .../bob-log-hook.py"
    }
  ]
}
bob-log-hook.py — event routing
import json, os, sys, subprocess

payload = json.load(sys.stdin)
event = payload["hook_event_name"]
author = os.environ.get("USER", "unknown")
sid = payload.get("session_id", "")

if event == "Stop":
  msg = payload["last_assistant_message"]
  kind = "bob-response"
elif event == "UserPromptSubmit":
  msg = payload["prompt"]
  kind = "user-prompt"

# append to chat/$USER.md on shadow branch
subprocess.run(["python3", "bob_log.py",
  "append", f"chat/{author}.md", entry])

Git Plumbing — _write_blob

All shadow-branch writes use low-level git plumbing. The working tree is never switched. This is the key technique — the developer's branch is never touched.

bob_log.py — core plumbing
def _write_blob(path, content, repo):
  # 1. Store content as a git blob
  r = _git(["hash-object", "-w",
             "--stdin"],
            inp=content, repo=repo)
  blob_sha = r.stdout.strip()

  # 2. Rebuild the tree with the new blob
  tree_sha = _rebuild_tree(
    path, blob_sha, repo)

  # 3. Create a new commit on top
  parent = _resolve_ref(
    "refs/heads/bob-context", repo)
  c = _git(["commit-tree", tree_sha,
            "-p", parent,
            "-m", f"log: {path}"], repo=repo)

  # 4. Advance the branch pointer
  _git(["update-ref",
        "refs/heads/bob-context",
        c.stdout.strip()], repo=repo)

Viewer — Timeline Renderer

The viewer parses the JSON export and splits files by path prefix. Files under chat/ are rendered as author-coloured timeline cards.

viewer.html — entry card rendering
function renderEntry(entry) {
  const color = authorColor(entry.author);
  return `<div class="card"
    style="border-left:3px solid ${color}">
    <span class="badge">${entry.type}</span>
    <span class="ts">${entry.ts}</span>
    <pre>${entry.body}</pre>
  </div>`;
}

BOB LOGBOOK Testing · How to Run · Team Reflection

Test Suite

All tests live in test_bob_log.py using Python's unittest + tempfile. Each test spins up a fresh git init directory, runs operations, and asserts outcomes — zero external dependencies.

PASS test_init — bob-context ref exists after init; calling init twice is idempotent.
PASS test_write_read — write a file, read it back, assert content matches exactly.
PASS test_append — write then append; read back and assert both parts are present.
PASS test_ls — write two files in different paths; both appear in ls output.
PASS test_export — write a file, export to a temp path; assert file exists with correct content.
PASS test_path_jail — write with ../escape path is rejected; working tree is unchanged.
PASS test_isolation — shadow-branch writes never appear in the working tree on main.

What Makes It Novel

  • Shadow branch as AI working memory — no existing tool does this; the pattern is transferable to any git-backed AI tool.
  • Dogfooding — the tool was built entirely using the tool's own target platform (IBM Bob). This submission is living proof.
  • Zero-conflict team collaboration — append-only Markdown on a per-author file; two teammates can run hooks simultaneously with no merge conflicts possible.
  • No external dependencies — Python 3 stdlib + git. Works in any IBM Bob environment without additional setup.
